Changelog
=========

Version History
---------------

**v2.2.0** (2026-11-11)

* Package the compact demo dataset so the PyPI Quickstart runs after a clean install.
* Add ``load_demo()``, a lower-case ``pysmatch.matcher`` import path, and a balance report based on standardized differences.
* Add explicit ``random_state`` support and actionable errors for invalid workflow state.
* Improve PyPI metadata, CI coverage, citation metadata, issue templates, and release notes.

**v2.1.2** (2026-03-08)

* Improve matching speed for large score arrays.
* Publish the v2.1.2 package and GitHub release.

**v2.1.1** (2026-02-25)

* Align dependency and documentation metadata for the 2.1 release line.

**v2.1.0** (2026-02-25)

* Publish the 2.1 feature release.

**v2.0** (2025-05-29)

* Publish the 2.0 release with the current modeling and matching workflow.

**v1.6** (2025-04-03)

* Fix bugs and improve the original matching workflow.
